# In Between

Commercial web-based card gaming platform for the Chinese New Year card game "In Between" (`射龙门`).

## Planned stack

- Frontend: Next.js, React, Tailwind CSS, Phaser.js
- Backend: NestJS, PostgreSQL, Redis
- Goals: mobile-friendly, iframe embeddable, wallet API ready, multilingual, admin-enabled, scalable

## Status

Project scaffold starting point. Backend implementation will be added first in Phase 1 MVP.
